# Data Transformation & Visualization

# Overview
This project involves creating an interactive sales report for a global store dataset using Power BI. The report provides insights into sales performance, shipping modes, and geographical segmentation to help stakeholders make data-driven decisions.

# Objectives

  1. Data Cleaning: Ensure the dataset is accurate and ready for analysis.
  2. Data Visualization: Create meaningful charts and graphs segmented by:
     *. Country
     *. Region
     *. Market
  3. Shipping Analysis: Visualize the percentage distribution of shipments based on ship modes.
  4. Sales Insights: Display sales trends across cities, states, regions, and markets.
  5. Interactive Dashboard: Develop a Power BI dashboard for stakeholder use.
